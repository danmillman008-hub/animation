How to help

Pose mode: drag a joint dot to rotate that part (children follow). With IK on, dragging a hand/foot solves the elbow/knee. Shift+drag = rotate only that part.

Pivot mode: drag a dot to move the pivot itself (fix a bad joint). Saved into rig_patch.json.

Keys: name a pose, set its time (s), Add key. Click a key to edit it. Save poses.json writes everything; drop the file in the workspace and I wire it into Main.tsx.

Keys: R reset pose · M mirror f/b · ←/→ prev/next key · Del delete key.
